# Smooth Cursor для OBS Studio

Плавный курсор и приближение за курсором в духе Screen Studio — только вживую, в OBS на Windows.

*Screen Studio-style smooth cursor and follow zoom for OBS Studio on Windows, as a single Lua script.*

## Что умеет

- **Сглаженный курсор** — движение через пружину (жёсткость и трение настраиваются), вместо дёрганого системного.
- **Крупный чёткий курсор** — свои текстуры 128px: стрелка (тёмная как в macOS или светлая как в Windows), рука, I-beam. Вид переключается сам по системному курсору.
- **Сжатие при клике** и **размытие в движении**, опционально — наклон в сторону движения.
- **Приближение за курсором** — автоматически при клике и/или по горячей клавише; камера плавно следует за курсором с мёртвой зоной в центре кадра.

Всё рисуется одним шейдером-фильтром на источнике, отдельные сцены и группы не нужны.

## Установка

1. Скачайте репозиторий целиком (папка `cursors` должна лежать рядом со скриптом).
2. OBS → **Сервис → Скрипты → «+»** → выберите `smooth-cursor.lua`.
3. На источнике **«Захват экрана»** → **Фильтры → «+» → «Плавный курсор (Smooth Cursor)»**.
4. По желанию: **Настройки → Горячие клавиши → «Smooth Cursor: приближение вкл/выкл»**.

Системный курсор в источнике фильтр отключает сам (галочка «Скрыть системный курсор в источнике»).

## Настройки фильтра

| Параметр | Что делает |
| --- | --- |
| Стиль / размер курсора | Тёмная или светлая стрелка, размер в пикселях |
| Жёсткость пружины, трение | Насколько быстро курсор догоняет мышь и сколько в нём инерции |
| Сжатие при клике | Масштаб курсора при нажатой кнопке |
| Размытие в движении, наклон | Эффекты при быстром движении |
| Приближение, x | Кратность зума (1 — выключено) |
| Приближать автоматически при клике | Зум по клику, держится заданное число секунд |
| Скорость приближения / следования | Динамика камеры |
| Мёртвая зона камеры | Доля кадра, внутри которой камера не двигается |
| Монитор | Какой монитор захватывает источник (по умолчанию определяется по размеру) |

## Ограничения

- Только Windows и только «Захват экрана» — для захвата окна или игры координаты курсора не пересчитываются.
- Нестандартные курсоры (изменение размера, крестик, загрузка) рисуются обычной стрелкой.
- Курсор сглаживается только в картинке OBS — на самом экране он остаётся обычным.
- После удаления фильтра галочку «Захват курсора» в источнике нужно вернуть вручную.

Проверено на OBS Studio 32.0.2.

## Свои курсоры

Текстуры генерируются скриптом `tools/gen-cursors.ps1`:

```powershell
powershell -File tools\gen-cursors.ps1 -OutDir cursors
```

Если меняете форму или хотспот — поправьте таблицу `CURSORS` в начале `smooth-cursor.lua`.
